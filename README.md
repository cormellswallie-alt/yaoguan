## 这是什么

爻观是一款 Android 上的**六爻纳甲排盘**工具。我们想做的是：

1. **起卦要真**：摇钱起卦的随机性来自量子物理过程和手机传感器噪声，不用任何伪随机算法。每一卦都留有可查的熵源凭据。
2. **排盘要准**：严格按京房八宫纳甲法装卦，六亲、六神、世应、伏神、卦身、旬空、月破、暗动、动变关系一样不少，并用经典卦例做单元测试。
3. **经文要正**：卦爻辞逐字对齐清康熙武英殿本《御纂周易折中》，配有白话简释。
4. **界面要美**：新中式视觉，**本卦与变卦同屏对照**，一屏读完整个盘。
5. **断语要诚实**：能用经文断的用经文（一爻独发取该爻爻辞），规则推演的结果明确标注为“理论推测”。

> ⚠️ 本应用用于传统文化研究与学习。排盘断语不构成任何决策建议。

## 真随机：每一枚铜钱从哪里来

计算机常用的 `Math.random()` 是**伪随机**：由确定的公式从“种子”推算，知道种子就能复现全部结果。爻观的摇钱起卦只使用**物理过程**产生的随机性。

### 熵源

| 熵源 | 物理过程 | 说明 |
|---|---|---|
| [ANU QRNG](https://qrng.anu.edu.au) | 真空电磁场的量子涨落 | 澳大利亚国立大学。公共接口限速 1 次/分钟，App 一次取 96 字节缓存在熵池 |
| [LfD QRNG](https://lfdr.de/qrng_api/) | 光子在分束器上的量子选择 | 德国 LfD 实验室 |
| 加速度计 / 陀螺仪 | MEMS 器件热噪声 + 手部不可预测的微动 | 摇动手机时连续采集；“离线摇钱”仅用此源，每爻须攒满 32 帧 |
| 触摸时序 | 手指按下时刻的亚毫秒级抖动 | 辅助熵 |

### 每一爻的生成过程

```
  量子字节（16 B）  ┐
  传感器原始读数    ├─▶ 拼接 + 爻位/时间标签 ─▶ SHA-256 ─▶ 取首字节低 3 bit
  触摸时间戳        ┘                                         │
                                                              ▼
                                         bit=1 → 背（计 3）  bit=0 → 字（计 2）
                                         三枚之和：6 老阴 ×  7 少阳  8 少阴  9 老阳 ○
```

- **SHA-256 只做“搅匀/白化”**，不产生新的随机性；随机性全部来自上游物理样本。
- 每枚铜钱消耗恰好 1 bit，0/1 等概率，**没有取模偏差**。
- **熵充足性检查**：量子字节 ≥ 16（128 bit），或传感器保守估计 ≥ 64 bit。都不满足时抛出 `NO_ENTROPY`，界面提示重试或改用离线摇钱。
- **不使用** `Math.random()`，也**不使用** `crypto.getRandomValues()`（它是 CSPRNG 输出，按“物理真随机”的要求不计入熵源）。冒烟测试会把这两个函数替换为“一旦调用即报错”的桩来验证。

### 可验证

每一卦保存 `trng` 凭据：每爻的熵源列表、量子原始字节（hex）、SHA-256 摘要、时间戳。排盘页 →「查看每一爻的熵源凭据」可以看到全部明细，以及对该卦量子字节做的 **NIST SP800-22 Monobit** 检验 p 值。「我的 → 熵源自检」可随时测试各量子源连通性与随机性。

实现见 [`www/js/trng.js`](www/js/trng.js)。

## 功能一览

### 起卦
- **摇钱**（默认）：量子熵 + 传感器熵；摇动手机或轻触「摇」，逐爻自下而上成卦，可撤回上一爻（撤回的随机结果作废，不复用）
- **离线摇钱**：不联网，仅用传感器物理噪声
- **时间起卦**：梅花易数（年支数 + 农历月 + 日）÷8 上卦，加时辰数 ÷8 下卦，总数 ÷6 动爻
- **报数起卦**：两数或三数
- **汉字起卦**：按字的 Unicode 码位分上下卦
- **手工装卦**：逐爻指定少阳 / 少阴 / 老阳 / 老阴，适合录入线下卦例
- 记录所问、分类（事业、求职、财运、感情、健康、考试、出行、寻物、官司……）、求测人身份 / 性别 / 生年，起卦时间可自动或指定

### 排盘页
- 本卦 / 变卦卦名、卦宫、世数、六冲 / 六合标识，并列显示
- 四柱 + 旬空
- 排盘表：六神 · 伏神 · 本卦六亲干支五行 · 爻象 · 世应 · 动爻 · 变卦爻象 · 变卦六亲干支
- 爻下小字：旺衰 / 用神 / 卦身 / 月破 / 暗动；变爻：回头生克、化进退神、化合、化墓、化绝、反吟、伏吟
- 神煞（贵人、日禄、驿马、桃花、羊刃、文昌、华盖、将星、天医）及其所临之爻
- 互卦 / 错卦 / 综卦
- **爻位详解抽屉**：月建、日辰对该爻的作用，旺衰，日长生，与诸爻的生克冲合，爻辞、小象、白话；可上下翻爻

### 断卦页
- 综合吉凶五档（大吉 / 吉 / 小吉 / 平 / 凶）
- 用神与世爻强弱条
- 五行生克图（用、世、原、忌标注）
- 要点列表（用神旺衰空破动变、原神忌神发动、六冲六合等）
- 应期推演时间轴（用神值日、出空、冲动、合住、生用之日）
- 应验反馈：已应 / 未应 / 待验

### 卦例库
- 按月分组，分类筛选、全文搜索（所问 / 卦名 / 笔记）、收藏
- 应验率环图与统计
- 每卦可写多条笔记；一键复制卦例文本；JSON 导出 / 导入

### 万年历
- 月历每日干支 + 节气；选中日的四柱、节气第几日、旬空、驿马 / 桃花 / 贵人、宜忌
- 标出有起卦记录的日子

### 卦典
- 64 卦按**文王卦序**或**京房八宫**排列
- 卦辞 / 彖传 / 象传 / 爻辞（含小象与白话）/ 纳甲装卦，互错综卦跳转

### 我的
- 量子随机源开关、熵源自检、真随机原理说明
- **屏幕刷新率**：自动 / 60 / 90 / 120 Hz，自动识别本机支持的档位，实时显示实测 fps
- 震动反馈、默认性别、数据导入导出与清空

## 吉凶判断：经文断语与理论推测

断卦页的总体吉凶分两种情况：

### 一爻独发 → 以爻辞断

只有一爻发动时，直接取**该爻爻辞中的吉凶断语**。断卦卡片显示「一爻独发 · 以爻辞断」、所据爻位、断语词与爻辞全文。

384 爻的断语等级由 [`tools/data/jixiong.py`](tools/data/jixiong.py) 生成：

1. 按断语词表（元吉、大吉、贞吉、终吉、吉、无不利、悔亡、无咎、无悔、吝、厉、悔、凶、贞凶、征凶、无攸利、灾眚……）自动提取，以句末结论性断语为主，并处理“厉…无咎”“贞吉…悔亡”“有凶有吉”等组合；
2. 对条件句、无明确断语或语义转折的爻（如“潜龙勿用”“先否后喜”“小贞吉，大贞凶”“妇人吉，夫子凶”），参照朱熹《周易本义》逐条**人工复核**。

分布：大吉 23 · 吉 112 · 小吉 116 · 平 79 · 凶 54。结果文件：[`tools/data/jixiong.json`](tools/data/jixiong.json)。

### 其余情况（多爻发动 / 静卦）→ 理论推测

沿用规则引擎：综合用神与世爻的旺衰（月令、日辰、动爻生克、空破、回头生克）、原神忌神是否发动、六冲六合等计分，映射为五档。界面会标注 **「理论推测」**，并注明“此结论由旺衰、生克、动变规则推算得出，属理论推测，非经文断语”。

> 用神强弱、生克图、应期时间轴在两种情况下都属于规则推演，仅供参考。

## 构建与开发

### 环境

- Node.js ≥ 20、JDK 21、Python 3.10+
- Android SDK（本地构建时需要；CI 已自带）

### 本地预览

`www/` 是纯静态页面，任意静态服务器即可预览（量子源需联网；刷新率、震动等原生能力在浏览器中不可用）：

```bash
npx serve www      # 或 python3 -m http.server -d www
```

### 构建 APK

```bash
npm install
npm test

pip install fonttools brotli pillow
npm run fonts      # 子集化字体 → www/fonts/
npm run icons      # 生成图标 → assets/

npx cap add android
npx capacitor-assets generate --android \
  --iconBackgroundColor '#B0352A' --splashBackgroundColor '#12100D'
npx cap sync android
python3 scripts/patch_android.py

cd android && ./gradlew assembleRelease
# 产物：android/app/build/outputs/apk/release/app-release.apk
```

### 持续集成

- 推送到 `main` / 提交 PR：测试 → 字体与图标 → 生成 Android 工程 → 打补丁 → 构建 APK → 上传 Artifacts（保留 30 天）

### 签名

`ci/debug.keystore`（密码 `android`）是**公开的测试签名**，作用仅是让每次构建的 APK 能互相覆盖安装。正式发布请生成私有 keystore，存入仓库 Secrets，并修改 `scripts/patch_android.py` 中的 `signingConfigs`。

## 常见问题

**摇卦时提示“物理熵源暂不可用”？**
量子源需要联网。ANU 公共接口每分钟只允许 1 次请求，App 会同时向 LfD 请求并缓存；若两者都失败，可重试，或改用「离线摇钱」（用力摇动手机采集传感器噪声）。

**为什么不用 `crypto.getRandomValues()` 兜底？**
它虽然吸收了系统的硬件噪声，但输出本身是密码学伪随机数生成器（CSPRNG）的结果。为了满足“物理真随机”的要求，爻观宁可不出卦也不使用它。

**选了 120Hz，实测还是 60 fps？**
刷新率最终由系统决定。部分机型在省电模式、温控或厂商策略下会限制应用申请高刷；也有机型需在系统设置中开启“高刷新率”或将应用加入高刷白名单。

**数据存在哪里？会上传吗？**
卦例、笔记、设置都只保存在本机（WebView localStorage），不会上传。唯一的网络请求是向两个量子随机数源取随机字节。可在「我的」导出 JSON 备份。

**断语准吗？**
一爻独发的断语来自经文；其余为规则推演的理论推测。排盘是工具，判断在人。
